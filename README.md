<h1 align="center">MikroTik3 | Learning Platform</h1>

---

A modern learning-platform application explorer

## Tech Stack

- **NestJS** — a framework for building server-side applications.
- **Prisma** — an ORM used for database management.
- **Redis** — an in-memory data store used for caching and session handling.
- **Docker** — a platform for containerizing applications.
